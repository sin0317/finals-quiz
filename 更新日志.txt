v1.15.0    2026-10-24 21:03
批注、背诵形式、改完题能重答
----------------------------------------------------------------------

【新增】题目批注
  · 答完一道题、看到正确答案时，反馈卡片里有「✎ 写一条」，
    写自己的易错点、口诀、老师强调的那一句。
  · 下次再遇到这道题、选完答案之后，批注才跟正确答案一起出现。
    答题前连 DOM 都不渲染 —— 提前露出来等于泄题。
  · 批注跟着题目走，不另建表：存进 q.memo，导出题库 JSON、导入、
    云同步都带着；错题本和收藏夹的列表里也能直接改、直接删。

【新增】背知识点的「形式」下拉
  · 三种：全部考填空（默认）/ 全部给选项 / 混合。
  · 混合模式下，掌握度过 60% 的题转成填空。
  · 和刷题同一条硬规矩：没有两个以上原卷选项就不给选项，
    名词解释、简答永远手打。

【修复】改完题立刻回到「没答过」
  · 以前保存改法后还停在原先那次「答错了」的回顾里，看不出改动、
    也没法按新版重答。现在卡片回到初见：输入框 / 选项回来、
    反馈清空，重答一次按新版判分。

【修复】改题不再污染整场记录
  · 答题结果从「按顺序 push」改成「按题号存」，只清正停着的这道；
    从别的页面改别的题，不会动这场刷题。
  · 结账页用 filter(Boolean) 数已答题，空洞不会被算成两道题。

【修复】细节
  · 窄屏下题目右上角「☆ 收藏 / ✎ 改题」被挤成两行 ——
    .q-meta 允许换行、按钮 flex:0 0 auto 不允许被压缩。
  · 清掉 toast 里残留的示例文案。

v1.14.0    2026-10-24 20:31
收藏夹、补充导入、老版 .doc
----------------------------------------------------------------------

【新增】收藏夹
  · 刷题卡右上角「☆ 收藏」，单题收藏 / 取消。
  · 「做题本」旁边新增「收藏夹」页签：可按当前题集 / 全部题集查看，
    按收藏时间或掌握度排序，一键「刷收藏的题」，一键清空。

【设计】收藏记在题目上（q.fav 时间戳），不另存收藏表
  · 题目在收藏就在，题目删了收藏跟着没。
  · 跟着题集导出、导入、云同步走。

【新增】补充导入
  · 导入页第三张卡：题集生成后又拿到新卷子 / 新笔记，随时补进去。
  · 不做文件分类，卷子和笔记混着选，程序自己判断 ——
    认得出带选项的选择题就当试卷照抄，认不出就当笔记挖空。
  · 判重看两样：id 和原文句子。同一句话挖不同的词 id 会变，
    只看 id 会整批重复。重复的题标「已有」、默认不勾、勾了也跳过。

【新增】老版 .doc（Word 97-2003）支持
  · 按 OLE 复合文档解析 FAT / DIFAT / 目录 / mini 流，读 FIB 的 fcClx
    定位 piece table，压缩片按 windows-1252、非压缩片按 utf-16le
    抠出正文，再包成一个最小 docx（zip STORE + 自算 CRC32），
    交给同一套 docxToText 解析。
  · 转换结果可在文件列表点「存 .docx」下载。

【边界】只保正文文字与段落，样式、图片、表格、页眉页脚不带；
  Word 6/95（nFib < 0x00C1）走 fcMin..fcMac 老路，只认单字节字符集。

v1.13.1    2026-10-24 19:47
选完文件却什么都没发生
----------------------------------------------------------------------

【根因】
  var files = input.files; input.value = '';
  Chromium / Edge 里清空 value 会把 FileList 就地清空，
  之前拿到的引用长度变成 0，importFiles 收到空数组后静默返回。
  表现就是「点了打开，文件没上传」。

【修法】
  新增 takePicked(input, kind)：先用 slice 把 FileList 拷成数组，
  再清 value，最后把快照交给 importFiles。

【为什么测试没抓到】
  happy-dom 的 files getter 每次返回拷贝，不是活列表，
  天然测不出这类生命周期 bug。补的回归测试手搓了一个
  「Chromium 语义的假 input」（清空即清列表），
  再用真实 Edge + DataTransfer 注入做端到端确认。

v1.13.0    2026-10-24 19:30
导入拆成两步
----------------------------------------------------------------------

【背景】在这之前，「导入」是一张卡、一个文件框，原卷和笔记只能二选一。

【新增】上下两张步骤卡，顺序固定、第一步可跳过
    第一步 · 导入原卷（可选）  → 照抄入库 = 真题库
             ↓                  这一库题决定「选择题从哪来」
    第二步 · 导入笔记（必做）  → 先去翻真题库：
                                翻到出原题，翻不到挖成填空

  · 顶部流程条把「1 导入原卷 [可选] → 2 导入笔记 [必做]」写在最显眼处，
    每张卡标题也标着「可选 / 必做」；第一步做完流程条自动亮起，
    底部提示变成「真题库：N 道原卷题，来自 M 个章节」。

【新增】两个文件框都是 multiple
  · 一次可以选十几个（一章一个文件很常见）。
  · 逐个读、边读边显示「正在读取 3/12…」，一个文件坏了不影响整批。
  · 读进来的文件列在输入框上方：文件名 + 字数 + 逐个移除 + 合计。

【规则】两步填同一个课程名，才会归进同一个题集
  · 课程名从文件名里猜：临床药物治疗学概论 第三章.docx
    → 课程「临床药物治疗学概论」、章节「第三章」。
  · 纯章节名不瞎猜，留给你填。

【删除】所有内置专业题库
  · 用户来自各个专业，预置一份药学的卷子对别人只是噪音。
  · 删掉只对某个专业有意义的 assets/paper_bank.json，
    页面里不再有「载入《某课程》原卷」这类按钮。
  · 解析器只认排版、不认学科。

v1.12.0    2026-10-24 18:36
括号里写的是词
----------------------------------------------------------------------

  · 卷子上不印字母、直接把答案写成词的
    （药物治疗的核心问题是（合理用药）），自动降级成填空题，
    不再当成选择题瞎猜。
  · 只认含汉字的短括号：（ADR）、（AUC）这种缩写，（4分）、（1）
    这种分值题号，（见第三章）、（包括中药）这种补充说明，
    都不会被当成答案抢走。
  · 前提：这一行得有题号（1. / 2、），或者前面没有正在收的题，
    否则一行没标号的「药品（包括中药）说明书」容易被误判成填空题。

v1.10.0    2026-10-24 18:13
选择题只认卷子原题
----------------------------------------------------------------------

【原则】选择题的题干和选项只能来自用户上传的卷子，
  不许系统自己编干扰项。笔记解析因此变成两路：

    笔记句子 ──► 先在题库里翻原卷真题
                   ├─ 翻到了（相似度 ≥ 0.45，或题干被这句话整个包住）
                   │    └─► 出卷子那道题：题干、ABCD 选项、答案，
                   │        一个字不改；笔记这句退到「讲解」位置，
                   │        答完显示「笔记里怎么说」
                   └─ 翻不到
                        └─► 按笔记挖空出填空，不给任何选项

  · 拿一份 302 句的精简笔记实测：224 道原卷题里 131 道（58%）
    能对上笔记，阈值附近的样本抽查都是对的。
  · 笔记里本来就印着 A/B/C/D 的成题不算编造，照旧出选择题 ——
    选项是原文写的，系统没动手。
  · 题库里已有这道题时，只补讲解，不重复出一条。

======================================================================
三、遗留边界（已知、这一轮没动）
======================================================================

  1. 填空题的答案集中写在区块末尾（而不是逐题写在括号里）的卷子，
     还解析不了。
  2. 括号里写词要当答案，这一行得带题号，否则容易被当成正文。
  3. 笔记和原卷的对应靠字面相似度（不是模型）。换个说法、
     同义改写就未必对得上 —— 对不上的不会硬凑成选择题，
     只会老实出填空题。
  4. 单次导入的题集上限 400 题。
  5. 广场没有点赞 / 评论，只有分享、取用、删除。
  6. 登录只接了 WorkBuddy OAuth 和昵称密码，微信 / QQ 需要
     备案域名与资质，暂未接。

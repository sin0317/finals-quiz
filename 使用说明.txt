期末刷题站 · 使用说明
================================================

一、怎么跑起来
------------------------------------------------
需要 Node 18 或更高版本（node -v 可查看）。

    cd 本目录
    npm start

然后浏览器打开 http://localhost:3000
想换端口：PORT=8080 npm start

没有 Node 也能用：直接双击 index.html，
    · 出题、刷题、背知识点、错题本、统计全部照常
    · 只是没有登录和云同步（页面会显示「离线模式」）

二、账号是可选的
------------------------------------------------
· 不登录 = 游客，所有功能都能用，数据存在这台设备的浏览器里
· 登录后：题集和练习记录会存到服务端，换电脑 / 换手机登录同一个账号就能接着刷
· 退出登录不会删本地数据，只是不再同步

两种登录方式（在登录弹窗里）：
  ① 使用 WorkBuddy 登录 —— 点一下跳 WorkBuddy 授权页，回来就登录好了，
     不用记密码。首次登录会自动建账号，昵称取 WorkBuddy 的名字。
     这种方式需要从线上地址打开（OAuth 要回调到已注册的域名），
     本地 localhost 或双击 index.html 用不了。
  ② 昵称 + 密码 —— 老办法，本地跑服务时也能用。

站长：第一个登录成功的账号自动成为站长，
      在「⑤ 数据统计」页能看到站点使用情况（谁注册了、多少游客、
      每人多少题、正确率、最近 7 天活跃）。
      普通账号看不到这块。

三、文件说明
------------------------------------------------
index.html   页面结构
styles.css   样式（支持深浅色）
app.js       全部前端逻辑：出题、判分、刷题、背诵、统计、云同步、题库还原、
             加粗标记识别与「识别不出转填空」
server.js    后端（零第三方依赖，只用 Node 自带模块）
package.json 启动脚本
vendor/      WorkBuddy 登录 SDK（本地托管，不走外网 CDN，断网也不白屏）
data/        运行时自动生成的数据库（users.json / cloud.json / stats.json / plaza.json）
test/        测试脚本

三·六、笔记里怎么标注考点
------------------------------------------------
两种写法，效果一样：

    Markdown 加粗：所选药物对患者具备**安全、有效、经济、适当**四个要素
    单星号也认：  所选药物对患者具备*安全、有效、经济、适当*四个要素
        都会出成：所选药物对患者具备____四个要素
                  （多选，答案 安全 / 有效 / 经济 / 适当）

    · 加粗写的是并列内容（用顿号隔开）→ 出多选题；单个词 → 出单选或填空
    · 加粗顶在句首也认：「**安全**是药物治疗的首要前提」→「____是药物治疗的
      首要前提」，考的就是加粗的那个词，不会把考点当成已知条件
    · 星号本身不会出现在题面里，只是标记

识别不出结构的句子，一律转成填空题，不直接丢掉：
    · 「…比值不变，又称之为恒比消除」→「…比值不变，又称之为____」（答案 恒比消除）
    · 引子再长也不丢句，长句会把后半截挖空
    · 引导词（又称之为 / 指的是 / 包括 等）留在题干里，答案才干净

但下面这些会照旧跳过，因为出了就是垃圾题：
    · 选项行（A. xxx、A、xxx B、xxx）—— 它们是选择题的一部分
    · 章节标题（第十四章 xxx）、卷面说明（单选题（每题 2 分））
    · 简答提纲（常用的给药方案设计方法有哪些）、分值（（10 分））

三·六·五、五种题型各自怎么考
------------------------------------------------
笔记里怎么写，就按那个分区考：

  单选题   「一、单选题」那一节里，句子里有明确考点的挖空考
  多选题   「二、多选题」那一节里，列了 A~E 选项就按多选出；
           卷子上没标正确项字母的，一律当「全选」（列出的都对）
  填空题   句子里的考点挖空，自己把空填上
  名词解释 只保留冒号前面的名词当题干，你默写后面那整段解释
           （例：笔记写「药物警戒：研究、收集、监测…的一门学科」，
             题干就是「药物警戒」，答案是你写的整段解释）
  简答题   题干就是那个标题（「药物治疗方案制定的一般原则」），
           答案是下面那串要点，你一条条打字答，答中几条算几条

手打题的输入框是大文本框，Enter 是换行，**Ctrl+Enter**（Mac 上 ⌘+Enter）交卷。
判分不要求一字不差：
  · 名词解释按关键内容命中多少给分，写错几个字、换个说法都认得
  · 简答按要点算，提交后把标准答案的要点一条条列出来，答到的打勾、漏掉的留着
  · 这两类题**不会自动跳到下一题**，答案一直在，看完自己点「下一题」

三·六·六、出题出得不对？教它一次，以后都按你的版本出
------------------------------------------------
解析器难免猜错：空挖多了、把单选题的选项并进了题干、名词解释被当成填空。
不用回头改笔记再重新提炼，直接在刷题卡片右上角点「✎ 改题」：

  ① 这题该怎么考    填空 / 单选 / 多选 / 名词解释 / 简答，随时换
  ② 题干            在框里用鼠标选中要考的那几个字，点「✂ 把选中的字挖成空」，
                    系统会把这段字换成 ____，并自动填进下面的答案框
                    （挖几个空就选几次；名词解释/简答不用挖，直接写标题）
  ③ 答案            多个空 / 多个正确项用顿号隔开；
                    名词解释填整段解释；简答一条要点一行（或分号隔开）
  ④ 想补充一句      可留空，写给自己看，例如「后面那句是解释，不用挖」

点「保存，以后都按这个出」之后：

  · 这张卡片立刻换成你的版本，题型标签也跟着变（改成单选就出选项）
  · 改法记在这道题上，不是只改这一次：刷新、登录后换设备同步、
    导出 JSON 都带着；下次抽到还是你的版本
  · 改成单选 / 多选时，选项自动从题库里配干扰项；
    题库太小凑不出干扰项会自动降级成填空，不会给你一道只有正确答案的「选择题」
  · 改错了点「恢复系统原样」，一步退回解析器原来的出法
  · 重新提炼同一份笔记时，之前教过的改法会按原文句子认领回来，不用重教

答完题看到「✎ 这题出得不对？」也能进同一个面板 —— 那时候才知道
标准答案对不对，改起来更准。

背知识点（③）里的卡片：
  · 名词解释：上面是名词，下面是整段解释，一起背
  · 简答：上面是标题，下面把全部要点列出来
  · 多选：题干 + 所有正确项

三·七、填空题怎么判分 · 回看上一题
------------------------------------------------
填空题是自己打字的，判分比选择题宽松：答出要点就算对，个别字写错、
次序颠倒也能认出来；只沾个边的算「记住了大半」，算半个对。

    · 提交后立刻判定：✅ 正确 / 🟡 差一点 / ❌ 记错了，都会给出正确答案，
      题干那个空也会直接补上标准答案（绿色高亮）
    · 中文输入法打字时按 Enter 是在选候选词，那一下不会被当成提交，
      候选词正常上屏，选完再按一次 Enter 才交卷
    · **答完一律停在这一题**，答案不会自己消失 —— 以前那个「答完自动下一题」
      开关已经去掉了，翻页只认你点「下一题 →」。选择题也一样，答对答错都停住
    · 判定卡片会自动滚到屏幕中间，电脑上也不会掉在视口外面看不到
    · 你正在打字时不会有任何东西来冲掉，打了一半的内容一直在

题号旁边有「← 上一题」，随时能回头看已经答过的题：
    · 回顾里显示你当时的作答和正确答案，题干空格同样补上标准答案
    · 可以一路往前翻（「← 更早一题」），点「继续第 N 题」回到进度
    · 回看只是看，不会重复计入练习记录，也不能重答

三·八、题集广场（⑥ 题集广场）
------------------------------------------------
把自己做好的题集分享给同学，也直接取用别人分享的。

怎么分享：
    · 右上角「分享我的题集」，或在我的题集上右键 →「分享到广场」
    · 必填两个标签：专业（如 药学）、科目（如 临床药物治疗学），
      同学主要靠这两个标签筛；可再加一句推荐语
    · 分享的是题目和答案；你的练习记录不会跟着分享
    · 分享需要登录（题集要存到服务器上）；浏览和取用不用登录
    · 同一份题集再分享一次 = 更新，不会叠两条；取用数会保留
    · 不想分享了随时可以撤下（已经取走的副本不受影响）

怎么取用：
    · 进「⑥ 题集广场」，按专业 / 科目 / 关键词筛，或按取用数排
    · 点「加入我的题集」就复制一份到自己的题集里（标题带「（广场）」，
      记得作者是谁），直接开刷
    · 同一份重复点不会多出副本

隐私与边界：
    · 广场是公开的：任何人（包括游客）都能看到分享的题目和答案，
      别把不想公开的内容分享出去
    · 列表页只传标题和标签，不传题目正文；取用才拉全文
    · 只能撤下自己分享的；站长可以下架任何一条

三·九、③ 背知识点：先看卡片，看满 20 张再做题
------------------------------------------------
这个板块分两段，不是一进来就考你。

第一段 · 知识卡片：
    · 点「开始看知识点」，一次一张，正面就是完整的那句话，
      被挖空的地方已经填回去并高亮 —— 先看清楚知识点本身
    · 「下一张 →」「← 上一张」随便翻，翻过的不会重复计数
    · 顶部显示「已看 3 / 12 张」，看够了才出现「开始做题 →」；
      知识点不足 20 张时，看完最后一张就解锁

第二段 · 挖空自测：
    · 看完点「开始做题」才进入，这时才是挖空让你自己填
    · 判分、给答案、看首字提示，都跟以前一样
    · **答完同样停在这一问**（以前这里 2.8 秒就自动跳，答案刚出来就没影了），
      底部写着「手打题不会自动跳，看完答案再点」，点「下一问」才继续
    · 想重新过一遍知识点，「再背一轮」会回到卡片从头看

四、安全说明
------------------------------------------------
· 密码用 scrypt 加盐哈希保存，磁盘上不存在明文密码
· 登录会话是随机 token，写在 HttpOnly Cookie 里，JS 读不到
· 登录接口有频率限制（同一 IP 5 分钟最多 12 次），防止暴力破解
· 服务端不会对外提供 data/ 目录和 server.js 的访问
· 每个人的题集互相隔离，接口层做了校验
· WorkBuddy 登录的账号没有密码，无法用「昵称+密码」的方式登录进去

五、版本号
------------------------------------------------
网页最下面那条灰字就是当前版本，例如「期末刷题站 v1.5.0」。
它和 package.json 的 version、接口 GET /api/version 是同一个数，
想确认线上跑的是不是最新一版，看页脚最快、或者：
    curl https://<你的域名>/api/version
发新版时改 package.json 的 version，同时把 index.html 页脚里那个数字改掉；
测试会核对这两处，改漏了会直接报错。

版本号右边还有一个「★ 给我 Star」小按钮，点了会在新窗口打开 GitHub 仓库，
想收藏或提 issue 都从那里去。二维码、微信群之类要加也可以，说一声就行。

六、数据存在哪
------------------------------------------------
服务端：./data/ 目录下三个 JSON 文件
        （进程退出时会自动保存；每 0.8 秒防抖落盘一次）
浏览器：localStorage（游客模式下的题集与记录）

想备份就把 data/ 整个目录复制走；
想清空所有账号，删掉 data/users.json 后重启服务。

八、常见疑问
------------------------------------------------
Q：同学注册的昵称会被别人看到吗？
A：只有站长能在「站点使用情况」里看到昵称和使用数据，普通用户之间互相看不到。

Q：两个人不同设备同时改同一个题集会冲突吗？
A：合并策略是「只增不减」：题集按课程名合并、题目取并集、
   练习记录取练得更多的那份。不会覆盖掉任何一边。

Q：想把站分享给同学，一定要有服务器吗？
A：不登录就能用，所以直接把 index.html 发过去双击打开也行，
   只是各人的数据各自留存、无法同步。要同步就得跑服务端。
